# OpenCode Go

Turn your OpenCode Go subscription into a Home Assistant conversation agent, AI Task and image generator.

- Live model catalog: new models work without updating the integration.
- No default model: choose the model per agent and get a clear error if OpenCode
  retires it.
- Streaming replies, Assist tool calls, AI Tasks and image generation.
- OpenAI, Anthropic and Gemini protocols routed from the live catalog.
- Installs through HACS as a custom integration.

See the [README](README.md) for installation, setup, troubleshooting and
development instructions.
